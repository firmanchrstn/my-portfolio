Project Document description View PRD (PDF)

01. Background

Context

Ketidakpastian waktu tunggu dan penumpukan antrean fisik di fasilitas kesehatan meskipun layanan pendaftaran online tersedia.

02. Challenge

Problem Statement

Antarmuka pemantauan antrean yang membingungkan bagi pengguna awam dan tidak adanya estimasi waktu panggil secara real-time.

03. Innovation

The Solution

Perancangan antarmuka berbasis UCD yang diintegrasikan dengan notifikasi proaktif WhatsApp dan prediksi Machine Learning.

04. Status

Current Progress

Ongoing: Pengumpulan dataset antrean rumah sakit dan tahap awal identifikasi kebutuhan (UCD).
